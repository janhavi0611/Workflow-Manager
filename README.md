# ✅ To-Do List Web Application (Django)

A clean and user-friendly **To-Do List Web App** built using the **Django Framework** that helps users organize and manage daily tasks efficiently.

This project includes **User Authentication** (Signup, Login, Logout) so every user can maintain their own private task list securely.

---

## 🌟 Project Overview

The **To-Do List Web Application** is designed to improve productivity by helping users:
- keep track of tasks,
- update progress,
- and stay organized in a simple interface.

Each user gets a **personal dashboard** where they can manage their own tasks without interference from others.

---

## ⚙️ Features

### 🔐 Authentication & Security
- User Signup / Login / Logout
- Each user has a separate task list
- Secure session-based login system

### 📝 Task Management
- Add new tasks
- View all tasks in one place
- Mark tasks as completed
- Edit / Update existing tasks
- Delete tasks easily

### 🗂️ Task Status & Organization
- Completed vs Pending task view
- Simple and minimal UI for fast usage

### 💾 Database
- Uses **SQLite** (Django default database)
- Data handled using Django ORM

### 💻 UI & Design
- Responsive frontend
- Built using **HTML, CSS, and Bootstrap**
- Works smoothly on both laptop and mobile screens
